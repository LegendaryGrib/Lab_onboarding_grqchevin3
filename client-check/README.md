# Проверка компьютера

`pc_info.bat` собирает сведения о Windows, процессоре, памяти и диске C, а затем проверяет список установленных программ. Отчёт сохраняется рядом со скриптом в `pc_report.txt`.

## Базовые категории

- Офисный пакет: Office, LibreOffice, OpenOffice или МойОфис для работы с документами.
- Браузер: Chrome, Firefox, Edge или Яндекс Браузер для веб-сервисов. Edge учитывается как компонент Windows, а не как признак настройки рабочего места.
- PDF: Acrobat, Foxit или SumatraPDF для чтения документов.
- Архиватор: 7-Zip, WinRAR или WinZip для почтовых вложений.
- Антивирус: Defender, Kaspersky, ESET или Dr.Web для защиты компьютера.

## Программы для проверки

Скрипт ищет игровые платформы и игры, торрент-клиенты, мессенджеры, а также программы для развлечений и оформления. Найденные названия выводятся по группам. Это только повод проверить назначение программы: скрипт не определяет, как давно она запускалась, и не предлагает автоматически её удалять.

## Проверка

После запуска проверьте временную метку, все пять базовых категорий, четыре группы дополнительной проверки и итоговый счётчик рекомендаций. Чтобы увидеть положительные результаты поиска, на компьютере должны быть установлены программы из соответствующей группы; для отрицательных результатов проверяйте отсутствие программы этой категории. В этой сессии BAT не запускался, так как для этого потребовалось бы создавать локальные файлы на компьютере. Поэтому сформированный `pc_report.txt` и снимок консоли `screenshot_audit.png` ещё не добавлены.

## Ограничения

Скрипт сравнивает только названия программ из разделов реестра для 64- и 32-битных приложений. Он не определяет фактическое использование программ и может не распознать приложение с необычным названием. Мессенджеры, игры и другие найденные программы могут быть нужны для работы; решение о них принимает администратор.
