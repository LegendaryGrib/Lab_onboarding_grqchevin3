# Разбор скрытого кода

После декодирования получается:

```text
import os; os.system('rm -rf /')
```

Команда пытается удалить файлы в системе. Это может повредить операционную
систему и уничтожить данные.

Не запускайте неизвестный текст через `exec`. Сначала проверьте его.
Подозрительный код запускайте только в отдельной безопасной среде.
