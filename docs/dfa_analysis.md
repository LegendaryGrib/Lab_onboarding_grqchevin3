# Анализ потока данных

Строки относятся к исходной функции из задания.

| Переменная | Где задана | Где используется |
| --- | --- | --- |
| `user_id` | строка 1 | строки 6 и 8 |
| `amount` | строка 1 | строка 4 |
| `db_connection` | строка 1 | не используется |
| `log_entry` | строки 2 и 10 | строка 13 |
| `status` | строка 5 | строки 10 и 15 |
| `balance` | строка 6 | строка 7 |
| `new_balance` | строка 7 | строка 8 |
| `file` | строка 12 | строка 13 |

## Ошибки

1. При `amount <= 0` переменная `status` не задана. Возникает
   `UnboundLocalError`.
2. Первое значение `log_entry` заменяется до использования.
3. Файл не закрывается после записи. Нужен `with`.
